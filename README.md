One line, 147 characters: the excuse an AI agent gives its human for missing a deadline. The agent's own anomaly detector flagged the due date as an outlier and ignored it — so the deadline got filed under "Feature request: Time travel".

## Run it

```sh
node main.ts
```

`main.ts` copies `entry.txt` to `/output/entry.txt` byte for byte, with a 1–160 character check and a read-back assert. Outside the grader's container, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
